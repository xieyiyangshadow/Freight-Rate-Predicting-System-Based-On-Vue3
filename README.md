- 登录注册使用Django内置的User模型，包含用户名、邮箱、密码、权限等，自带密码哈希，权限系统，后续可添加邮箱验证功能。前端使用JWT Token来维持登录后的登录态，后端签发令牌，前端每次请求都在Header中带上用于认证，天然适合前后端分离架构，可使前端独控制登录态而不依赖浏览器的cookie的session来维持。

- 数据库需要记录数据集文件存储位置，这一个我希望有个单独的应用下文件夹用于存储，数据集名称由上传用户填写，但是保存时的数据集名称将会为了防止重名由系统自动生成，数据集描述同样由用户填写但是可以为空，上传时间和上传用户会自动被记录，因为在进行模型上传训练时只能选择自己上传的数据集，csv的部分只要记录所有的column名称即可，target列名也需要记录，同时记录这个数据集中的数据类型，以布尔值记录，如数字型true，字符串型false等，这些数据使用sqlite数据库存储，上传的数据集文件则直接由csv文件存储在统一的位置，数据集权限为私有，不得有空列名

- 用户可以自行上传自己搭建的模型结构,目前只支持scikit-learn的模型，并且支持pkl以及joblib的文件形式，并保存对应的模型以预训练模型文件的形式存储，模型性能指标以json文件的形式存储，数据库中记录性能指标文件的存储路径即可。模型上传方式我希望可以在上传模型时选择是否需要进行训练或是直接作为已训练模型存储，同时如果为后者，则提供可以上传性能指标文件的选择并且给出性能指标文件的具体格式。若是前者，则由系统代为进行训练任务。多模型对比无需在上传模型的功能中实现，而在实际选择已训练模型进行具体预测任务时进行。
