# Freight-Rate-Predicting-System-Based-On-Vue3

使用Element Plus组件库搭建Vue3项目，要求尽量使用python语言或c++语言，后端使用Django架构使用python语言编写业务逻辑，组织结构完善，具备用户友好性，可读性，可扩展性，不同文件夹职责明确

包含注册、登录界面并支持使用SQLite数据库进行存储，主键为自动升序的用户唯一uid，同时在注册时要求用户提供用户名、电话号码、账号密码信息，若电话号码已被注册则提示“电话号码已有账户，请重试”的字样，登录时可以通过电话号码以及账号密码进行登录。当用户注册完成后会自动以注册的信息完成登录。

登录成功后则跳转到当前用户的个人中心仪表盘页面，左侧为导航栏，分别是：个人数据、预测模型、运价预测、历史预测。点击任一标签则会在右侧显示该标签对应的页面。

个人数据页面通过可视化图表分为多块展示用户当前正在进行中的任务数量、已经完成的任务数量、模型数量。

预测模型界面的功能有上传自定义模型，查看模型性能的功能，数据集是系统自带的存在某一指定文件夹中的csv表格，当用户上传模型后会自动使用数据集进行训练，训练时会自动将数据集分为训练集以及验证集并增加早停机制进行训练，若训练过程中报错则将该模型标注为训练失败。每个模型都有唯一的模型id作为主键保存在SQLite数据库中，包含模型权重存储路径，训练时长，模型性能，模型当前状态。状态有正在上传、正在训练、训练完成、训练失败四个状态。模型性能都会被作为txt文件以固定格式存储在模型id为文件名的文件中，可读取用于展示模型性能的可视化。只有训练完成的模型才能在云集啊预测界面新建任务时被选择。对每个已经上传的模型都会将训练后的模型权重使用如joblib库保存在本地文件夹内，每次在运价预测界面选择模型使用后都会自动导入用于预测。同时用户在模型训练完成后可以点击模型卡片进入模型详情，可以看到模型权重大小，模型在训练集以及验证集的训练效果，使用可视化的方式对模型性能进行展示。

运价预测界面可以新建任务，可以选择出发点和目标点以及使用的模型进行运价预测，模型可以多选，预测任务完成后将会归入历史预测内。

历史预测界面可以看到所有完成的运价预测任务，点击任务卡片后可以查看该任务的详情，包括多模型预测的结果，上下浮动等，这些都使用用户友好的数字以及可视化图表进行展示。同时也可以对任务进行删除，点击任务卡片上的删除按钮后再经过二次确认后才能完成删除。

运价预测任务将会被存储到SQLite数据库中，有唯一任务id作为主键，对每个任务都将其输出的数据保存到本地预测任务文件夹下的单独文件夹内，单独文件夹名称为该任务的唯一id。
